# Reliability audit — 2026-11-18

## Shizuku I/Oとダウンロードの失敗処理

Read separate output/error pipes while pumping APK input, bound the command deadline, and use the actual exit status for success. Open the APK before starting its receiver. Add download timeouts, cancellation propagation, incomplete-body rejection, partial cleanup and atomic publication. Local tests cover full pipes, timeouts, cancellation and partial bodies. No package install is performed.

No feature switches, boot preferences, signing identity, target scopes or Android 16/17 compatibility gates are changed. This is a source fix and regression check, not proof of physical-device behavior. No release APK is distributed by this audit.

## Clean-host build

The new source CI exposed a daemon criterion that required JetBrains Java 21 without providing a Linux download source. Keep the Java 21 requirement but accept an installed standard JDK, including CI Temurin, instead of restricting its vendor. This was not visible on the development host because Android Studio supplied that vendor.
